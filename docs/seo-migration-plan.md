# SEO Migration Plan

## 1. Goal
Preserve the existing SEO equity of `sritelanganaruchulu.com` while upgrading to a modern React SPA (with SSR/Prerendering via Vite plugins or a static generator if necessary for SEO) and Spring Boot architecture.

## 2. URL Mapping and Redirects
- **Current Product URLs:** `/product/{slug}/`
- **Current Category URLs:** `/product-category/{slug}/`
- **Current Info URLs:** `/about-us/`, `/contact-us/`, etc.
- **Action:** Maintain the exact URL slugs wherever possible. For any URLs that must change, configure server-side 301 permanent redirects in the load balancer/proxy (e.g., Nginx) or via Spring Boot interceptors.

## 3. On-Page SEO
- **Title Tags:** Unique for every product and category. E.g., `[Product Name] | Authentic Telangana Pindi Vantalu | Sri Telangana Ruchulu`
- **Meta Descriptions:** Extracted from the existing product short descriptions.
- **H1 Tags:** Ensure one `<h1>` per page (Product Name on PDP, Category Name on PLP).
- **Canonical Tags:** Point to the main URL of the page to prevent duplicate content issues.

## 4. Structured Data (JSON-LD)
- **Organization & WebSite:** On the homepage, mapping the logo and business info.
- **BreadcrumbList:** On category and product pages.
- **Product & Offer:** On Product Detail Pages (PDP), mapping name, image, description, price, and availability.

## 5. Technical SEO
- **Sitemap.xml:** Dynamically generated by the Spring Boot backend or statically built, containing all valid product, category, and informational pages.
- **Robots.txt:** Allow crawling of main pages, disallow `/cart`, `/checkout`, `/admin`, and search result pages.
- **Rendering:** Since we are using React, we must ensure search engines can read the content. Consider React Snap, Vite SSG, or configuring dynamic rendering (e.g., Rendertron/Puppeteer) if standard client-side rendering is insufficient, though Googlebot executes JS, it's safer to have SSR for e-commerce.

## 6. Pre and Post-Launch Checks
- Crawl the staging site with tools like Screaming Frog.
- Verify 301 redirects are in place.
- Submit the new `sitemap.xml` to Google Search Console post-launch.
- Monitor 404 errors in GSC.
