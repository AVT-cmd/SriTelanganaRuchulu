# Design System

## Brand Identity
- **Name:** Sri Telangana Ruchulu
- **Logo:** `https://sritelanganaruchulu.com/wp-content/uploads/2026/01/Sri_Telangana_Ruchulu_Logo_-_2__White_bg_-1_2-removebg-preview-150x150.png`

## Color Palette
Extracted from existing Kadence variables:
- **Primary Brand Color (Gold/Brownish):** `#D1A155` (Used for highlights, current menu items, buttons)
- **Secondary / Accent:** `#F6E7BC` (Warm cream/ivory)
- **Background / Header:** `#4a2e1f` (Dark brown/espresso)
- **Text (Dark):** `#000000` (Headings), `#111111` (Body)
- **Background (Light):** `#ffffff` (Main), `#F9F7F7` (Alternate light gray/off-white)
- **Accent Red (Errors/Sale):** `#b82105`
- **Accent Green (Success/In Stock):** `#13612e`
- **Accent Orange:** `#f7630c`

## Typography
- **Headings:** Montserrat (Clean, modern, premium feel)
- **Body:** Poppins, sans-serif (Highly readable for descriptions and UI elements)

## Visual Direction
- **Premium & Authentic:** Rooted in Telangana food traditions.
- **Card Design:** White backgrounds with subtle shadows `0px 15px 15px -10px rgba(0,0,0,0.05)`, square or slightly rounded corners (`4px` - `8px`). Avoid excessive rounding.
- **Spacing:** Generous whitespace, keeping sections distinct. `1200px` max-width container.
- **Buttons:** Solid primary color `#D1A155` with white text, or dark brown `#4a2e1f` with white text. Hover states use subtle shadow adjustments or slight color darkening.
- **Imagery:** Use authentic product photography extracted from the existing site.

## Components
- **Announcement Bar:** Dark brown background `#4a2e1f`, white text.
- **Header:** White background for main area or transparent over hero. Dark brown for top bar if present.
- **Product Cards:** Clean, image-focused, clear title, price, and primary CTA.
- **Badges:** Sale or Best Seller badges in `#D1A155` or `#b82105`.
